# دليل تعديل محتوى موقع سُبُل

## الدخول إلى لوحة المحتوى

- محلياً: افتح `http://localhost:3000/studio` بعد تشغيل `npm run dev`.
- بعد نشر الموقع: افتح `https://sobol.ps/studio`.
- سجّل الدخول بالحساب الذي تمت دعوته إلى مشروع Sanity.

إذا ظهرت رسالة **Trying to connect** وبقيت الحقول فارغة، فهذا يعني أن المتصفح لا يصل إلى خدمة Sanity. عطّل إضافة Bitdefender للموقع أو اسمح لهذه النطاقات، ثم أعد تحميل الصفحة:

- `http://localhost:3000`
- `https://sobol.ps`
- `https://*.sanity.io`
- `wss://*.sanity.io`

## أين أجد النصوص؟

- **إعدادات الموقع وبيانات التواصل:** اسم المؤسسة، العنوان، الهاتف، البريد، واتساب، ورسالة الاستشارة العامة.
- **القائمة الرئيسية والتذييل:** روابط القائمة العلوية وكل النصوص الموجودة أسفل الموقع.
- **الصفحة الرئيسية:** عنوان الصفحة الرئيسية، الوصف، الأزرار، ومراحل رحلة العمل.
- **صفحة من نحن:** مقدمة الصفحة، المنهج، الرسالة، الرؤية، المبادئ، والفريق.
- **صفحة الخدمات:** مقدمة الصفحة، باقات الخدمات، والخدمات التسويقية.
- **صفحة أعمالنا:** مقدمة الصفحة وقائمة الأعمال.
- **صفحة المدونة:** مقدمة الصفحة ونص «قريباً» والمواضيع المخطط لها.
- **صفحة تواصل معنا:** مقدمة الصفحة، نصوص التواصل، عناوين وعبارات نموذج الطلب.

النص الموجود حالياً في الموقع يظهر داخل هذه الحقول بمجرد اكتمال اتصال Studio.

## طريقة تحديث الموقع

1. افتح الصفحة المطلوبة من قائمة **تحرير المحتوى**.
2. عدّل النص أو الصورة أو الرابط.
3. افتح **معاينة الموقع** لمشاهدة التعديل قبل النشر.
4. اضغط **Publish / نشر** عندما يصبح المحتوى جاهزاً.
5. ينتقل المحتوى المنشور إلى الموقع تلقائياً عبر إعادة التحقق، دون إعادة نشر المشروع يدوياً.

الحفظ أثناء التحرير تلقائي، لكنه ينشئ مسودة فقط. لن يرى زوار الموقع التعديل حتى تضغط **Publish / نشر**.

## إخفاء العناصر وترتيبها

- فعّل **إخفاء هذا القسم من الموقع** لإخفاء قسم دون حذفه.
- اسحب العناصر داخل القوائم لتغيير ترتيبها.
- استخدم **Add item** لإضافة عنصر من النوع المسموح.
- لا تحذف المحتوى القديم إذا كنت تريد إخفاءه مؤقتاً؛ استخدم خيار الإخفاء.

التصميم والألوان والحركات محمية في الكود ولا يمكن تغييرها من لوحة المحتوى.
